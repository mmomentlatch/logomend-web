# LogoMend Web

Браузерна версія LogoMend. Відео обробляється локально за допомогою FFmpeg WebAssembly і не завантажується на сервер.

## Можливості

- видалення логотипа прямокутником чи точною кистю;
- відновлення фону через FFmpeg `removelogo`, OpenCV `inpaint` або швидкий `delogo`;
- покадрове відновлення OpenCV.js `cv.inpaint` для коротких відео до 15 секунд;
- додавання PNG, JPG або WebP-логотипа з позицією, розміром і прозорістю;
- обрізання початку та кінця відео;
- послідовна обробка: видалити → переглянути → продовжити → додати логотип/обрізати → завантажити;
- MP4 H.264 експорт зі збереженням роздільної здатності;
- українська, англійська, польська та німецька версії;
- централізована конфігурація Google AdSense.

## Оптимізація швидкості

- FFmpeg WebAssembly завантажується і компілюється у фоні одразу після вибору відео;
- OpenCV Web Worker попередньо прогрівається та повторно використовується протягом сесії;
- OpenCV обробляє лише область логотипа, а не повні кадри;
- обрізання кінця MP4/MOV виконується без повторного кодування і втрати якості;
- усі інші режими використовують швидкий пресет H.264 `ultrafast`.

## Локальний запуск

```powershell
pnpm install
pnpm run dev
```

Production-збірка:

```powershell
pnpm run build
```

Готовий статичний сайт створюється у `dist/`. Його можна розмістити на GitHub Pages, Cloudflare Pages, Netlify або звичайному хостингу без Python і бази даних.

## Публікація на GitHub Pages

Репозиторій містить готовий workflow `.github/workflows/deploy-pages.yml`. Після кожного push у гілку `main` GitHub автоматично:

1. встановлює залежності через pnpm;
2. перевіряє JavaScript;
3. створює production-збірку;
4. публікує папку `dist/` у GitHub Pages.

У репозиторії потрібно один раз відкрити **Settings → Pages** і вибрати **Source: GitHub Actions**. Для безкоштовного GitHub Pages репозиторій має бути публічним. Після першого успішного запуску сайт буде доступний за адресою `https://ІМʼЯ-КОРИСТУВАЧА.github.io/logomend-web/`.

## Реклама

Редагуйте тільки `public/ads-config.js`: увімкніть `enabled`, вставте свій `ca-pub-*` і три slot ID. Право змінювати та публікувати цей файл має бути лише у власника репозиторію.

## Обмеження Web

FFmpeg WebAssembly використовує пам’ять браузера. Для довгих, великих або 2K/4K-відео, а також STTN і багатокадрового відновлення використовуйте LogoMend Local.

Обробляйте лише власні матеріали або відео, на редагування яких маєте дозвіл.
