Умови використання

LogoMend призначений для законного редагування власних відео або матеріалів, на зміну яких користувач має дозвіл.

Відповідальність користувача

Не використовуйте сервіс для видалення чужих позначок авторства, обходу захисту, порушення авторських прав, прав на торговельні марки або умов платформ.

Відсутність гарантій

Результат залежить від формату, сцени, руху й можливостей пристрою. Сервіс надається «як є» без гарантії ідеального відновлення прихованого фону.

Збереження оригіналу

Завжди зберігайте початковий файл. LogoMend створює нову копію, але браузер або пристрій може завершити обробку через нестачу пам’яті.
